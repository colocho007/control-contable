## Limitaciones comunicadas

- Excel se entrega mediante CSV compatible con Excel.
- PDF se genera mediante impresion del navegador.
- El balance general formal depende de la clasificacion `tipo`/`subtipo` del
  catalogo.
- La prueba integral debe ejecutarse con usuarios reales.

## Declaracion de cierre

La entrega se considera aprobada solamente cuando no existen bugs bloqueantes,
el SQL critico y la configuracion productiva tienen evidencia, la prueba minima
esta completada, existe backup previo y las areas responsables firman esta acta.
